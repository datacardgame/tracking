# Market Tracker (Ragnarok: The New World)

สคริปต์นี้จำลองการเปิดตลาดในเกม อ่านรายการไอเท็มที่ขายอยู่และ option/สเตตัสของแต่ละชิ้น
ด้วยการจับภาพหน้าจอ + OCR แล้วสแกนซ้ำทุก 5 นาทีเพื่อบอกว่ามีไอเท็มใหม่ลงขายหรือไม่

ทำงานบน **PC (Windows)** เท่านั้น — ต้องเห็นหน้าต่างเกมอยู่บนหน้าจอจริงขณะรัน (ไม่ใช่รันในเซิร์ฟเวอร์/บนคลาวด์)
เพราะใช้การจำลองคลิกเมาส์และแคปหน้าจอจริง

## ข้อควรทราบก่อนใช้งาน

- นี่คือ automation ที่จำลองการคลิก/แคปหน้าจอ **ไม่ได้ต่อ API เกม** และไม่มีข้อมูล official ว่าเกมนี้มี PC client
  ทางการหรือไม่ — ถ้าเล่นผ่านอีมูเลเตอร์ (BlueStacks/LDPlayer) ก็ใช้สคริปต์นี้ได้เหมือนกัน แค่ต้องมองอีมูเลเตอร์
  เป็นหน้าต่าง PC ปกติ
- เกมส่วนใหญ่มีเงื่อนไขห้ามใช้ third-party automation/bot ในบัญชี ควรตรวจสอบ ToS ของเกมก่อน
  สคริปต์นี้แค่ "อ่าน" ข้อมูลตลาด ไม่ได้ซื้อขายหรือให้ความได้เปรียบในเกม แต่ความเสี่ยงเรื่อง ToS เป็นเรื่องที่คุณต้องตัดสินใจเอง
- ผลลัพธ์ OCR ไม่แม่นยำ 100% โดยเฉพาะถ้ามีฟอนต์เอฟเฟกต์พิเศษ/สีพื้นหลังไม่ตัดกับตัวอักษร ต้องคาลิเบรตและอาจต้องปรับ
  regex การแยกข้อความเองหลังดูผลจริง

## ติดตั้ง

1. ติดตั้ง Python 3.10+ (ถ้ายังไม่มี)
2. ติดตั้ง Tesseract OCR (ตัวโปรแกรม OCR หลัก ไม่ใช่แค่ pip package):
   - ดาวน์โหลดตัวติดตั้งสำหรับ Windows จาก UB-Mannheim tesseract build
   - ระหว่างติดตั้ง ให้ติ๊กเลือกภาษาไทย (`tha`) เพิ่มจากอังกฤษ (`eng`) ด้วย ถ้าข้อความในเกมมีภาษาไทย
   - จดจำ path ที่ติดตั้ง (ปกติ `C:\Program Files\Tesseract-OCR\tesseract.exe`) แล้วเอาไปใส่ใน
     `market_config.py` -> `TESSERACT_CMD`
3. ติดตั้ง Python packages:
   ```
   pip install -r requirements.txt
   ```

## โครงสร้างหน้า Trade House ที่สคริปต์นี้รองรับ

ออกแบบตามภาพหน้าจอจริง: รายการไอเท็มเป็นกริด **2 คอลัมน์ x 4 แถวต่อหน้า** แต่ละการ์ดมีชื่อ,
ชื่อ special skill (คั่นด้วยจุลภาค), ราคา, ตัวจับเวลา และด้านล่างมีปุ่มเปลี่ยนหน้า (`‹ ›`) กับเลขหน้า
เช่น `1/2` สคริปต์จะ**คลิกไอคอนไอเท็มแต่ละใบ**เพื่อเปิด popup รายละเอียด (แสดงชื่อเต็ม, ประเภท,
Base Stats, และ Special Skill พร้อมคำอธิบาย) แล้วปิด popup ก่อนไปใบถัดไป จนครบทุกหน้า

## สถานะการคาลิเบรต

`market_config.py` ถูกกรอกพิกัดจริงไว้ให้แล้วจากภาพหน้าจอที่วัดมา (grid การ์ด, popup รายละเอียด,
ปุ่มเปลี่ยนหน้า, ปุ่ม All Items/My Favorites) **ใช้ได้ทันทีถ้าหน้าต่างเกมอยู่ตำแหน่ง/ขนาดเดิม
กับตอนที่วัดพิกัด** ถ้าย้าย/ปรับขนาดหน้าต่างเกม ต้องคาลิเบรตใหม่ทั้งหมดตามขั้นตอนด้านล่าง

หมายเหตุเฉพาะเกมนี้ที่ตั้งค่าไว้แล้ว:
- ผู้ใช้เปิด Trade House ทิ้งไว้ตลอด ไม่ต้องกดเปิดเอง สคริปต์รีเฟรชลิสต์ก่อนสแกนทุกรอบด้วยการ
  กดแท็บ **My Favorites** แล้วกดกลับ **All Items** (`refresh_item_list()` ใน `market_tracker.py`)
- ปิด popup รายละเอียดด้วยการ **คลิกพื้นที่ว่างนอกกรอบ popup** (กด Escape ใช้ไม่ได้ในเกมนี้)
  จุดที่ใช้คือท้องฟ้าว่างๆ เหนือการ์ดไอเท็ม (`CLOSE_POPUP_POS`)

## ขั้นตอนคาลิเบรตใหม่ (ทำเฉพาะตอนย้าย/ปรับขนาดหน้าต่างเกม)

พิกัดทุกจุดผูกกับตำแหน่ง/ขนาดหน้าต่างเกมบนจอคุณ เปิดเกม วางหน้าต่างในตำแหน่ง/ขนาดที่จะใช้ทุกครั้ง
(อย่าย้ายหลังจากนี้) แล้วเปิดหน้า Trade House ด้วยมือค้างไว้

1. ลองรัน `python auto_calibrate.py` ก่อน (ดูหัวข้อถัดไป) จะหากริดการ์ด + เดา popup ให้อัตโนมัติ
   ส่วนที่มันหาให้ไม่ได้ (ปุ่ม All Items/My Favorites, ปุ่มเปลี่ยนหน้า, จุดคลิกปิด popup) ให้หาด้วยมือ
   ผ่าน `python calibrate.py mouse` (กด Enter เปล่าเพื่อจับจุดเดียว, พิมพ์ `r` เพื่อจับกรอบ 2 มุม)

2. กรอกพิกัดทั้งหมดที่ได้ลงใน `market_config.py`

3. ทดสอบรันครั้งเดียวก่อน (แก้ `POLL_INTERVAL_SEC` เป็นค่าน้อยๆ ชั่วคราว หรือกด Ctrl+C หลัง
   รอบแรกจบ):
   ```
   python market_tracker.py
   ```
   ดู log ที่ print ออกมาว่าชื่อ/ราคา/special skill อ่านถูกไหม ถ้าไม่ถูก ให้ปรับ:
   - `parse_card_summary()` และ `parse_item_detail()` ใน `market_tracker.py` ตามรูปแบบข้อความ
     จริงที่ OCR อ่านได้ (ดูตัวอย่าง raw text ได้จาก `market_log.csv` หรือภาพใน `debug_screens/`)

## ถ้าสแกนจบแค่หน้า 1 แล้วหยุด (ไม่ยอมเปลี่ยนหน้า)

สาเหตุคือกรอบเลขหน้า (`PAGE_INDICATOR_REGION`) เล็กแค่ ~65x44 px OCR อ่าน `1/3` ไม่ออกบ่อย
สคริปต์ตอนนี้ตัดสินว่า "ยังมีหน้าถัดไปไหม" เป็น 3 ชั้น จึงไม่หยุดเองแล้วแม้ OCR อ่านไม่ออก:

| ชั้น | วิธีตรวจ | ต้องคาลิเบรตไหม |
|---|---|---|
| 1 | OCR เลขหน้าจาก `PAGE_INDICATOR_REGION` โดยไล่ลองหลายโหมด psm (`PAGE_INDICATOR_PSM_CANDIDATES`) จนกว่าจะแยกเป็น `n/m` ได้ | คาลิเบรตแล้ว |
| 2 | วัดความสว่างปุ่มลูกศรขวาที่ `NEXT_PAGE_CHECK_POS` (ปุ่มกดไม่ได้จะจางลง) | ต้องตั้ง `NEXT_PAGE_ENABLED_MIN_BRIGHTNESS` เอง (ไม่ตั้งก็ได้) |
| 3 | กดเปลี่ยนหน้าไปเลย สแกนหน้าใหม่ตามปกติ แล้วดูว่า "ได้ไอเท็มชุดเดิมกับหน้าก่อนไหม" ถ้าชุดเดิม = ปุ่มกดไม่ติด (หน้าสุดท้าย) ทิ้งผลหน้านั้นแล้วหยุด | ไม่ต้อง ทำงานอัตโนมัติ |

> **หมายเหตุ (เคยลองแล้วใช้ไม่ได้):** ชั้น 3 เวอร์ชันแรกใช้ "เทียบภาพลิสต์ก่อน/หลังกดปุ่ม"
> ซึ่งพังทันที เพราะทุกหน้าหน้าตาเหมือนกันหมด (การ์ดขาว 8 ใบตำแหน่งเดิม พื้นหลังเดิม) ต่างกัน
> แค่เส้นตัวหนังสือบางๆ ข้างใน — วัดจริงแล้วสองหน้าที่ไอเท็มคนละชุดกันเลยต่างกันแค่ **~0.9%**
> ของพิกเซล (แม้เทียบที่ความละเอียดเต็ม) เลยถูกตัดสินว่า "ไม่เปลี่ยนหน้า" แล้วหยุดที่หน้า 2
> จึงเปลี่ยนมาเทียบ **คีย์ไอเท็มที่ OCR อ่านได้** แทน ซึ่งเป็นสัญญาณคนละชั้นและแยกขาดชัดเจน

> **เรื่อง psm ของเลขหน้า:** ทดสอบกับภาพเลขหน้าจริง (`1/14`) แล้ว psm 7 ที่เคยล็อกไว้อ่านออกมา
> เป็น `'WAY:'` แต่ psm 13 (raw line) และ psm 8 (คำเดียว) อ่านถูกทั้งคู่ ตอนนี้จึงไล่ลองหลายโหมด
> แล้วเอาโหมดแรกที่ให้ผลเป็น `n/m` — และ**ห้ามเติมขอบขาวรอบภาพก่อนส่งเข้า OCR** (เคยลอง
> เพราะคิดว่าตัวเลขชนขอบ) เพราะวัดแล้วมันทำให้ psm 13 พังกลายเป็น `'wm'` ส่วนการ์ด/popup
> ก็ไม่ได้ดีขึ้น

### Tesseract อยู่คนละไดรฟ์ในแต่ละเครื่อง

สคริปต์จะใช้ `TESSERACT_CMD` ก่อนเสมอ ถ้าไฟล์ตรงนั้นไม่มีจริงจะไล่หาให้เองใน
`C:` / `D:` / `E:` (ทั้ง `Program Files` และ `Program Files (x86)`) แล้วค่อยหาใน `PATH`
พร้อมพิมพ์บอกว่าไปเจอที่ไหน ย้ายเครื่องแล้วไม่ต้องแก้ config

ตรวจว่าจุดที่ตั้งไว้เล็งตรงจริงไหม (ไม่สแกน ไม่คลิกอะไร แค่แคปภาพ + รายงานค่า):

```bash
python market_tracker.py checkpage
```

จะเซฟภาพ 4 ไฟล์ **ทับชื่อเดิมทุกครั้ง** (ไม่สะสมไฟล์ใหม่) วางข้างๆ ตัวสคริปต์:

| ไฟล์ | ดูอะไร |
|---|---|
| `debug_page_indicator.png` | กรอบเลขหน้าที่แคปมา — ครอบตรงตัวเลขไหม |
| `debug_page_indicator_ocr.png` | ภาพเดียวกันหลังปรับแต่ง = สิ่งที่ Tesseract เห็นจริง ถ้าตาคนยังอ่านไม่ออก ต้องขยับกรอบใหม่ |
| `debug_next_page_check.png` | กรอบรอบปุ่มลูกศรขวาที่เอาไปวัดความสว่าง |
| `debug_prev_page_check.png` | กรอบรอบปุ่มลูกศรซ้าย (ไว้เทียบตอนคาลิเบรต) |

วิธีตั้งเกณฑ์ชั้น 2: รัน `checkpage` ตอนอยู่ **หน้า 1** ครั้งหนึ่ง (ลูกศรขวากดได้ = สว่าง,
ลูกศรซ้ายกดไม่ได้ = จาง) แล้วกดไปหน้าสุดท้ายด้วยมือ รันอีกครั้ง เอาค่าลูกศรขวาสองครั้งมาเทียบ
แล้วตั้ง `NEXT_PAGE_ENABLED_MIN_BRIGHTNESS` ไว้ตรงกลาง — ถ้าค่าออกมาใกล้กันมาก (เกมไม่ได้ทำ
ปุ่มให้จาง) ปล่อยเป็น `None` ไว้ได้เลย ชั้น 3 รับมือแทนอยู่แล้ว

## การใช้งานจริง

```
python market_tracker.py
```

- สแกนทุก 5 นาที (แก้ได้ที่ `POLL_INTERVAL_SEC` ใน `market_config.py`)
- แต่ละรอบ print สรุปไอเท็มใหม่ที่เพิ่งลงขาย พร้อม option ออกทาง terminal
- บันทึกทุกไอเท็มที่สแกนเจอสะสมไว้ใน `market_log.csv`
- เก็บ snapshot รอบล่าสุดไว้ใน `market_last_snapshot.json` เพื่อใช้เทียบรอบถัดไป
- กด `Ctrl+C` เพื่อหยุด

## ไฟล์ในโปรเจกต์

| ไฟล์ | หน้าที่ |
|---|---|
| `market_config.py` | พิกัด/ค่าตั้งค่าทั้งหมด (แก้ตรงนี้เป็นหลัก) |
| `calibrate.py` | เครื่องมือช่วยหาพิกัดเมาส์/กรอบด้วยมือ ทีละจุด |
| `auto_calibrate.py` | ช่วยหากริดการ์ด + เดากรอบ popup ให้อัตโนมัติจากภาพหน้าจอ (ลดงานคาลิเบรตด้วยมือ) |
| `market_tracker.py` | สคริปต์หลัก รันลูปสแกนตลาดทุก 5 นาที |
| `market_log.csv` | ถูกสร้างอัตโนมัติ เก็บประวัติไอเท็มที่สแกนเจอทุกรอบ |
| `market_last_snapshot.json` | ถูกสร้างอัตโนมัติ เก็บผลรอบล่าสุดไว้เทียบหาไอเท็มใหม่ |
| `debug_screens/` | ถูกสร้างอัตโนมัติตอนรันจริง เก็บภาพแต่ละ region ที่แคปได้ (ปิดได้ที่ `SCREENSHOT_DEBUG_DIR = None`) |
| `auto_calibrate_debug.png`, `auto_calibrate_popup_debug.png` | ภาพตรวจสอบผลจาก `auto_calibrate.py` (ลบทิ้งได้ ไม่กระทบการทำงาน) |

## ข้อจำกัดที่ควรรู้

- ถ้าหน้าต่างเกมถูกย้าย/ปรับขนาด ต้องคาลิเบรตใหม่
- ถ้าคุณสลับไปทำอย่างอื่นบนคอมพิวเตอร์ระหว่างที่สคริปต์กำลังคลิก/สกอลล์ (mouse/keyboard ถูกใช้จริงบนเครื่อง)
  จะรบกวนการสแกน ควรปล่อยเครื่องว่างไว้ระหว่างสแกน
- ระบบเทียบ "ไอเท็มใหม่" ใช้ชื่อ+ราคา+ชื่อ special skill (ไม่รวมตัวจับเวลา เพราะเวลานับถอยหลัง
  เปลี่ยนทุกรอบอยู่แล้ว) ถ้าไอเท็มเดิมถูกลงขายซ้ำด้วยราคาต่างกัน จะถูกนับเป็นไอเท็มใหม่ด้วย
  (ตั้งใจให้เป็นแบบนี้ เพราะถือเป็น "ประกาศขาย" ใหม่)
- สคริปต์จะคลิกไอคอนไอเท็มทีละใบเพื่อเปิด/ปิด popup ทำให้ 1 รอบสแกนใช้เวลานานขึ้นตามจำนวน
  ไอเท็มทั้งหมด (8 ชิ้น/หน้า) ถ้ามีของขายเยอะและหลายหน้า ให้เผื่อเวลาสแกนให้น้อยกว่า 5 นาทีจริง
  ไม่งั้นรอบถัดไปจะเริ่มช้ากว่ากำหนด (สคริปต์จัดการให้เองด้วยการหักเวลาที่ใช้สแกนออกจาก
  `POLL_INTERVAL_SEC` แต่ถ้าสแกนนานเกิน 5 นาทีจะรันต่อทันทีโดยไม่รอ)
